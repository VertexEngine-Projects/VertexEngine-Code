# Security Policy

## Supported Versions

I monitor security and fix errors and vulnrabilites for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.7+     | ✅ Supported        |
| 1.5 - 1.6     | 🟡 Monitored Less       |
| < 1.4   | ❌ End of Life (EOL)|

Please ensure you are running the latest stable version from PyPI before reporting an issue.

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.** 

If you discover a security vulnerability within VertexEngine, I ask that you report it to me privately so I can fix it before it is disclosed publicly.

To report a vulnerability, please email me at: **FinalFacility0828@gmail.com**

### What to Include in Your Report:
* A detailed description of the vulnerability and the potential impact.
* Step-by-step instructions or a minimal Python script to reproduce the exploit.
* Any potential mitigation steps or fixes you suggest.

### Response Process:
1. **Acknowledgement:** I'll acknowledge receipt of your vulnerability report within **48 hours**.
2. **Investigation:** I'll investigate the issue and keep you updated as I work on a fix.
3. **Patch & Disclosure:** Once a fix is ready, I will release a new patch version to PyPI and coordinate a public disclosure timeline with you, giving you full credit for the discovery.
