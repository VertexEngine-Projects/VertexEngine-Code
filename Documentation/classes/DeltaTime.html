Delta Time

Description: Delta Time is a concept that is widely used in Game Engines. It makes movement more consistent across many computers by multiplying a variable's change with it. It makes it so that more FPS will have the same speed as less FPS, so 2 computers with different specs share the same game experience.

Example: 


                    class MainScene(Scene):
                        def __init__(self, engine):
                            super().__init__(engine)
                            self.x = 100
                            self.speed = 240  # pixels per second

                        def update(self):
                            self.x += self.speed * self.engine.delta_time
